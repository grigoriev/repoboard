# repoboard

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Repoboard gives a daily overview of the GitHub repositories you work with. It lives in the macOS
menu bar, polls the repositories through the `gh` CLI and notifies you about new issues,
discussions, replies, security alerts and Renovate pull requests that need you.

Work in progress.
